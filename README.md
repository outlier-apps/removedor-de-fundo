# Removedor de Fundo

Programa para Windows que tira o fundo de várias fotos de uma vez, com inteligência artificial rodando no próprio computador.

**Baixar:** [Removedor-de-Fundo.exe](https://github.com/outlier-apps/removedor-de-fundo/releases/latest/download/Removedor-de-Fundo.exe)

Precisa de uma chave de ativação, vendida na Basefy.

## Requisitos

- Windows 10 ou 11 (64 bits)
- Internet (para ativar a chave)

## Como usar

1. Baixe e abra o `Removedor-de-Fundo.exe`. Ele cria um atalho na Área de Trabalho.
2. Cole a chave de ativação e clique em **Ativar**.
3. Arraste as fotos, escolha fundo transparente ou branco e clique em **Remover fundo**. Na primeira vez o programa baixa o modelo de IA (cerca de 170 MB).

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.

O programa avisa sozinho quando sai uma versão nova.

## Componentes de terceiros

Este programa inclui o [FFmpeg](https://ffmpeg.org) (licença GPL), cujo código-fonte está disponível em https://ffmpeg.org/download.html, o modelo IS-Net/DIS (Apache 2.0) e o ONNX Runtime (MIT).
